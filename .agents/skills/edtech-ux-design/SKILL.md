# EdTech UX Design Skill

## Design Philosophy
1. **Calm Academic Dignity**:
   - Pravaah UPSC is an intensive study tool for serious Civil Services aspirants, not a gamified consumer app.
   - Eliminate distracting bright animations, neon gradients, and sensationalist badges.
   - Palette: Warm off-white/alabaster canvas (`bg-[#fbfbf9]` / `bg-stone-50`), soft stone borders (`border-stone-200`), dark charcoal body text (`text-stone-900`), and restrained deep forest/teal accents (`#0f766e` / `#115e59` / `#1e3a8a`).
2. **Devanagari & Bilingual Readability**:
   - Optimize font sizing and line heights for bilingual text: Hindi Devanagari script requires 10-15% more vertical line height (`leading-relaxed`) to prevent matra clipping.
   - Provide seamless Hindi / English toggle on all question cards and study materials.
3. **Clarity of Navigation**:
   - Core sidebar navigation must be focused and clean (maximum 8 primary items):
     1. Dashboard
     2. Learn / Syllabus
     3. PYQ Bank
     4. Practice Tests
     5. Mains Writing
     6. Current Affairs
     7. Spaced Revision
     8. Profile & Settings
4. **Honest Metrics**:
   - Never display artificial, fabricated counters (e.g., "Over 9,500+ PYQs" when the published bank contains 2,173 verified questions).
   - Display truthful, real-time database counts and transparently label feature readiness (e.g., "Controlled Beta", "Series A Verified").

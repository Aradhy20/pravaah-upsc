# Current Affairs Daily Record Template

Fields: date, headline, publisher, original_url, language, issue_area, syllabus_paper, prelims_tags, mains_tags, facts_and_figures, background, analysis_en, analysis_hi, pros_cons, way_forward, source_reliability, rights_status.

Workflow:
1. Capture article/release metadata and canonical URL.
2. Prefer primary government documents for factual claims.
3. Write an original concise summary in English and Hindi.
4. Map to UPSC syllabus and recurring themes.
5. Store facts with dates and citations; flag changing statistics.
6. Do not copy full newspaper articles or paid e-paper content.

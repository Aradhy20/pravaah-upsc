# Pravaah UPSC Master Library — Extraction Workspace

**Scope selected:** All UPSC examinations | 1995–present | complete preparation depth | English + Hindi.

## Important status
This package is a source-verified collection workspace and extraction tracker, **not a claim that every paper from 1995 onward has already been downloaded**. UPSC archive pages intermittently rejected automated Firecrawl connections during the first pass. The official links are preserved below so the archive can be harvested and verified in subsequent batches.

## Included
- Exam inventory for major UPSC examination families.
- Year-by-year harvest tracker (1995–2026) for each exam family.
- Official source catalogue and extraction log.
- Question, answer-key, bilingual note and current-affairs data schemas.
- English/Hindi directory structure.
- Firecrawl extraction workflow and quality-control checklist.

## Recommended data rules
1. Keep original official PDFs unchanged; record source URL, retrieval date, exam, year, paper, language and checksum.
2. Store official answer keys separately from coaching/provider answers.
3. Never label an unofficial explanation or machine translation as an official UPSC answer/translation.
4. Keep English and Hindi records linked by a common `question_group_id`; preserve original script.
5. For each question, store paper/page/question number and source citation.
6. Record missing years explicitly; do not infer that a missing paper never existed.
7. Mark exam-pattern changes and discontinued/restructured examinations.

## Copyright and redistribution
NCERT explicitly prohibits republication/redistribution of its textbooks and says links may be provided with written permission. Newspaper articles and e-paper editions are also copyrighted. This library therefore stores links, bibliographic metadata, user-created notes, and original summaries unless a source licence expressly permits copying. Do not mirror paid newspaper editions or protected coaching PDFs.

The tracker is seeded through 2026 (current year for this workspace). Extend the year range as needed.
